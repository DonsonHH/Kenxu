# 1.6.0：独立连接分类与阶段验收

2026-10-15。先核对 Kenxu `main` 和 Ansible `master`，原提交分别为 `054f35a`、`d8c0202`，均无新远端变更；GitHub Actions API 没有运行记录，不把它描述为 CI 绿灯。

## 上一步复核与本轮修正

Legacy Free 固定接口、省市／ASN 字段、7 天成功缓存和 5 分钟失败退避保留。管理员需对实际出现的公网来源触发查询，普通用户只能看本人最近使用 IP。未改第三方隐藏直连、China US 备用或 Microsoft 默认分流。

新增 `/api/meter/flows` 与 `/api/meter/flows/heartbeat` 只接受有效物理采集器 bearer，email 由服务端映射用户和逻辑节点，SG2／UK 不混记。对未注册身份、未来时间、非法目标和冲突序号失败关闭；幂等报告只确认。新数据独立保存在 `flow_events`，不写入 `usage_events`，不重复计费。

“使用日志”默认展示启用后实际连接字节；按主域名合并并展示 unknown，可切换历史关联区间。两种口径互不混合，历史关联排序仍不声称网站消耗排名。覆盖以新鲜心跳、采集范围和无积压为条件；核心重启或长时间断连后覆盖起点重置。新连接分类也会更新来源列表和个人中心最近 IP，但目标、省市等管理信息不进入用户接口。

元数据保留 30 天后脱敏，账本和幂等不回滚。计数点包含 TLS／HTTP 自身字节，不是下载文件净大小或 Azure 账单。IP／CDN 不猜测应用；未采集历史、停机及隐藏直连不补造数据。

## 校准和回归

- US2 独立网络命名空间：两用户／目标 TCP、1 万短连接、TLS／Reality＋Vision 长连接、UDP、MUX、多目标 XUDP 和来源迁移、正常退出尾部落盘全部通过独立字节核对。
- 原版复现长连接延后提交，以及首次并发注册竞争。修复不重写旧账本，不能据此断言历史异常全部由它们导致。
- 五组无并行上传的交替性能测试，合并样本 p95 6.485→8.048 ms；CPU 中位数 +7.6%，吞吐和内存通过预设门槛。不是公网延迟保证。
- 短 HTTPS 并发另用 SSL MemoryBIO＋独立目标 socket 校验：原版与候选可多转发 24 字节的连接收尾记录，原生和观察值与目标端严格相等；不把客户端应用输入当作完全同口径，也不以此解释历史 GB 级用量。
- 55 项 Node 回归、完整 8 个隔离 Edge 浏览器脚本、23 项 Python 回归；Go 观察模块／dispatcher／mux 正常及 race 检查。浏览器覆盖新旧口径切换、手机深色无溢出、原始日志延迟加载和角色隔离。
- 门户上线核对 6 位用户实际 18 份订阅响应，账号／授权／密钥／凭据／规则与已有历史账本一致。
- 五台运行二进制 SHA-256 一致；从干净固定上游提交应用仓库补丁后重新构建，SHA-256 与线上一致。已固定构建源导出换行，避免 Windows Git 配置造成不可复现。

## 分阶段发布

US2 单账号试点经过独立目标字节、生产请求、门户入库和角色隔离复核后，按 US2 全账号 → US1 → SG1 → SG3 → SG2 推广。五台物理核心／六条逻辑线路全部启用；SG2 与 UK 使用不同计量身份。逐台检查真实 Reality 连接、原生与观察累计守恒、私有接口、配置一致和队列；UK 实际出口验证为 GB，普通 SG2 为 SG，未改转发拓扑。

首次切换因代码目录权限触发回退，原服务恢复；已修复代码目录可遍历权限、上传后二进制执行权限，并验证最终安装哈希。既有凭据、规则、订阅与历史账本不重建。新增分类是从启用时开始的短时生产验证，不声称历史数据获得逐网站解释，也不代替长期 soak。

源码、构建、测试与回退详见 [Ansible 落地说明](https://github.com/DonsonHH/my-ansible-playbooks/blob/master/docs/kenxu-flow-rollout.md)。SIGKILL／断电仍可丢尚未落盘的窗口；不能宣称任意故障零丢失，也未完成所有客户端组合的长时间 soak。

最终线上复核：5 个采集器均为 `all-managed` 且无积压，6 位正式用户均显示 6/6 逻辑线路覆盖，已有新连接的账号可见实际网站分类；普通用户不能访问目标／省市管理接口。仅覆盖实际启用后的记录，旧账本不变。

交叉复核补修：旧关联样本和新连接来源合并时，先对完整 IP 集合去重后再限制显示前十，防止用两个 Top 10 列表估算总数而漏计；16 个来源的回归测试先失败后通过，接口仍只返回最近十项，不扩大列表负载。
