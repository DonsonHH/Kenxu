## 诊断结果：没有把推测写成已发生的故障

当前安装 **Cockpit Tools 1.3.70**，专属核心为 **Mihomo 1.19.31**；外层 Clash Verge 核心为 **1.19.32**。只读检查实际进程可执行路径、Windows TCP 归属、系统代理开关及 Clash 控制接口：

- 检查当时 TUN 关闭、Windows 系统代理关闭，Clash 为 rule 模式，进程识别为 strict。
- Cockpit 主程序的已建连接均为本机连接，专属 Mihomo 存在远程连接，但没有连入本机 Clash 7897；外层连接表没有观察到 Cockpit。
- Cockpit 的全局代理开关关闭，未配置全局上游。

因此**本次没有重现当时正在发生的双重代理**，不声称已证明历史大流量或高延迟由它引起，也不承诺本轮一定降低多少用量或延迟。隔离测试复现的是“若专属引擎出站被外层捕获，缺少例外就可能继续走外层代理”的条件路径。

检查 v1.3.70 的官方源码确认：专属引擎是独立进程，配置经 stdin 发送，启动时清除继承的 HTTP_PROXY / HTTPS_PROXY / ALL_PROXY 等代理环境变量；节点资源导入不接受订阅中的系统代理、TUN 或分流规则。因此仅开启系统代理，不必然让该原生核心再次使用它。TUN 捕获、显式选择本机 Clash 上游、原客户端继续使用旧入口，是需要区分的情况，不能只看两款程序同时运行就断言嵌套。

## 实现与范围

规则正文位于[公开、无凭据的示例](../examples/cockpit-windows-direct.rules.txt)。使用 `PROCESS-PATH-REGEX`，完整锚定 Windows 路径中的 `.cockpit_tools\\proxy-engine\\release-…\\mihomo.exe`，大小写不敏感，匹配当前安装器使用的 release 目录格式；不根据裸进程名放行，不把 Codex、整个 Cockpit 主程序或 AI 域名设为 DIRECT。

hdc 原为“继承”，本次通过带 Origin、CSRF 和修订校验的真实私有管理接口改为**优先补充**，只增加这条首位规则；之后仍继承全站原有 125 条规则。节点、组名、账号独立凭据、订阅令牌和原有 OneDrive / Microsoft / AI 分流不变。没有为了此功能增加后端模块或更换源配置。

这里的 DIRECT 是“外层直接连接内部选定的代理节点”，不是让 Codex 绕过内部代理直连 AI 服务。内部账号仍按 Cockpit 绑定的节点出站，受管节点仍正常计量；没有把流量改为不计量、没有回删或减半历史记录。Stash 会移除桌面进程规则，Shadowrocket 只导出节点，因此两种移动格式保持不变。

以下不在此规则的覆盖范围：手动把 Clash 端口填成 Cockpit 上游；由宿主进程直接发起的 HTTP／SOCKS 代理；其他操作系统、旧版或自定义引擎路径；外层处于全局模式、关闭进程识别或实际 TUN 驱动未能提供进程归属。这些情况需要单独诊断，不能自动替用户换节点。进程路径匹配也是路由条件，不是可执行文件签名验证或本机安全隔离。

## 测试先失败，再修正

`node test/cockpit-core.mjs <Windows-Mihomo路径>` 使用两个临时核心、回环 HTTP 目标和虚构的外层代理。内层核心复制到临时目录中的专属目录结构，外层通过真实进程识别得到其路径，不伪造连接元数据，也不读取实际节点或账号。

1. 没有规则时，真实外层连接为 `Match → Fixture outer proxy`，观察到一跳外层代理，断言应为 DIRECT 失败。
2. 加入示例规则后，同样的专属引擎流量命中 `ProcessPathRegex → DIRECT`，外层代理访问数为 0。
3. 普通调用者仍走原来的代理兜底，外层代理访问数变为 1，没有整机直连。

使用实际安装的 **1.19.32 和 1.19.31** 两个版本分别通过上述检查，最终还在与外层相同的 `strict` 进程识别模式下复测通过。临时核心只监听回环、不启用 TUN，没有操作正在运行的核心。临时目录在解析绝对路径并验证属于系统临时目录后清理，子进程与测试连接均回收。

新增 `test/cockpit-rules.test.mjs` 通过真实管理接口与订阅 HTTP 路径验证：个人规则首位导出、原列表顺序不变、节点授权和签名不变、朋友与移动格式不变，未来全局规则仍可继承；另验证不同 Windows 用户／目录／大小写及非专属 Mihomo、Codex、伪后缀等不匹配场景。完整 **78 项 Node 测试**通过，生产依赖审计无已知漏洞。
