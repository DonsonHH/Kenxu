# 1.4.5：未计量备用节点的用户端展示

用户端节点可见性独立于计量登记。私有源节点可使用布尔值 `kenxu-user-hidden`，从用户节点列表、状态结果及相关数量中隐藏备用线路。管理员保留完整节点清单，配置导出移除此内部标记，客户端仍收到原授权的节点、策略组和规则。

本轮 China@US 仅增加用户端隐藏标记，不注册采集器、不改授权、不改用户凭据或历史用量。美国主节点的故障切换组保留原顺序，只有两个主节点均不可用时才走备用，辅助组继续隐藏。

复核覆盖未计量节点不注册计量即可隐藏、用户与管理员接口范围、远程配置字节不变、未授权账号隔离、非法标记拒绝、桌面与手机界面、既有 JP 直连及历史保留。线上发布采用完整数据备份、原子版本切换和失败回退。

最终验证：43 项后台测试通过；隔离浏览器确认桌面与手机的用户端隐藏、管理员保留节点；5 个账号的 15 份远程导出与变更前字节一致；10 次真实用户接口检查不再返回隐藏备用；255 种授权组合未出现无效引用。真实 Mihomo 的主节点失效／恢复切换仍按原方案运行。

界面隐藏不等于移除订阅中的节点，也不能阻止已授权用户查看连接参数。
