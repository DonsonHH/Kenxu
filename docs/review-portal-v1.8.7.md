# 1.8.7：原界面的交互与动画打磨

2026-10-18。保留现有界面布局、配色和导航结构；本次不采用「轨道空间」样板，不改节点、分流规则、授权、计量或后端接口。

## 更新范围

- 复制订阅使用原位确认，保持按钮几何，减少重复通知；格式／身份变化后丢弃旧反馈。
- 两端登录、保存、重置和手动刷新显示准确的等待状态，保留防重复提交、就近错误与重要安全提醒。失败不清空可读的旧统计，不误报刷新成功。
- 原生弹窗保留即时逻辑关闭和表单清理，指针操作增加短过渡；键盘及低动态即时响应。WebKit 的触发按钮显式传入，修正关闭返回焦点。
- 手机导航关闭后 inert，不进入屏幕外 Tab 路径；菜单和遮罩可被快速操作打断，列表重绘后修复丢失的返回焦点。
- 范围／设备选项增加方向键与 Home／End；管理端页签保持原有缓存和键盘行为。轻量选中及 hover 反馈不改变尺寸，不新增图表／计量数字动画。
- 使用文档当前步骤跟随实际阅读，不抢焦点，不将阅读等同于完成。观察器随面板离开或退出清理，无支持时保留手动命令。
- 高对比度保留系统色静态选中标记，不禁用用户系统配色。
- 发布复查又锁定一个创建账号的焦点时序：在暂时禁用的触发按钮失焦且关闭事件先到时，旧回退逻辑会转到标题。修复为等待已有刷新收尾恢复按钮，且刷新失败也恢复可操作状态；使用阻塞真实 HTTP 响应和浏览器失焦边界的回归复现失败后修正，不靠加长断言等待。

细节见[第一批](review-interaction-feedback.md)、[第二批](review-overlay-interactions.md)、[第三批](review-microinteractions.md)及[合并验收](review-ui-acceptance.md)。这些记录描述各自本地提交时状态；本次版本才执行统一推送与部署。

## 发布原则

只将跟踪的源码、前端产物、测试与文档打包，排除 private、数据库、密钥、真实 SSH 配置及未跟踪的原型。保留上一发布目录，校验暂存产物后再切换 current；仅重启门户服务。门户自身承接的 WebSocket 可能短暂重连，节点核心、计量采集器、连接检测与 Tunnel 不因本次发布而重启。

采用 SQLite 一致性备份而非复制运行中的主文件；备份限私有权限并清除其中 IP／目标标签，不用旧备份覆盖新产生的用量。发布前后检查账号／授权／个人规则／组选项／凭据摘要、密钥、历史账本及实际订阅正文；不输出私有链接或节点凭据。
