# 1.10.0 私有 Jetson 链式分流复核

本轮新增可选第二份配置，原版交付保持不变。国内公网 DIRECT 规则经 Jetson 原生出站；国外原策略经 Jetson 再拨号到获授权自有 VPS。内网与 Tailscale 传输保持本机直连，原 REJECT 保留，第三方未计量备用不进入链式配置。

## 已完成的隔离检查

- 85 项单元／API 测试通过，包括绑定用户的两种远程交付、个人 UUID 不变、其他用户 cookie／签名订阅拒绝、私有管理员下载和停用后不可交付。
- 独立 Edge 浏览器验证指定用户／管理员入口、其他账号没有卡片和私有接口请求、退出清理、320／390／1440px 与深浅主题。现有管理工作流、公告权限与交互验收回归通过。
- 真实独立 Mihomo：国内站点及 donson.top 成功，规则命中 Jetson 直出；8 条获授权受管逻辑线路均可访问，出口国家和 IP 摘要与原版逐一对应。测试强制选择仅在独立内核中发生。
- Jetson 原生出站出口在国内；首跳 UDP DNS 查询成功。错误首跳凭据被拒绝，尝试通过首跳访问回环管理地址失败。
- 测试初期发现内核监听出现早于规则集就绪，已修正测试等待；每次出口请求使用独立连接，避免复用连接误判切换结果。单次 HTTP 耗时不视为 ping 或提速结论。

## 发布与限制

线上发布后需独立复核：全部既有三种格式订阅字节、受保护身份／授权／源规则、历史用量前缀、公开／私有健康、其他账号能力隔离及部署文件清单。发布结果记录在本地受控工作记录，不能用静态测试代替。

首跳通过 Tailscale 专有地址和独立认证开放，拒绝非 Tailscale 接口及私有目的地址；每分钟复核账号状态，失效时停止服务。客户端仍须自行启用需要的系统代理或 TUN。未切换用户正在运行的 Clash，也未更改 Windows／Cockpit 代理设置。

实测 PC 到 Jetson 当时走 DERP 香港中继，非点对点直连。因此链式版作为可选路径，不承诺降低延迟或提高吞吐。管理与撤销流程见 [私有链式配置](jetson-chain.md)。
