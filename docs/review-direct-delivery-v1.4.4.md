# 1.4.4：隐藏直连交付

受管的第三方线路可在受控运维迁移后改为直连、不计量，同时隐藏用户端节点和历史卡片。原始直连参数仍只提供给原先获授权并登记的账号；普通停用节点继续拒绝导出，不会自动退回共享凭据。

数据结构只添加默认关闭的 `direct_delivery` 和 `user_hidden` 两列，不删除账号、授权、签名密钥、计量凭据和历史用量。旧用量继续参与总量统计，管理员可查看原线路的历史。用户端显示和实际订阅交付分别控制，隐藏分组不是凭据保密。

验证覆盖：直连参数导出、授权与登记隔离、其他节点保持个人凭据、采集身份失效、历史保留、订阅链接不变、新账号及后续授权、用户端节点／历史隐藏、管理员标识、活跃采集器计数、手机布局。后台完整回归及隔离浏览器验证通过。

线上迁移使用独立发布目录、完整数据备份和原子切换。只在最后一个中转出口停止计量后停止对应中转与采集服务；源节点、分流规则和其他出口不变。敏感迁移脚本、数据库、订阅链接和上游参数不进入仓库。
