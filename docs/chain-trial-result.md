# Jetson 链式路径试验：已撤回

2026-10-27 对 hdc 的普通版与 Tailscale → Jetson → VPS 链式版进行配对测量后，决定退回 1.9.1 稳定代码。原有订阅、个人凭据、授权、规则、历史用量和普通节点均保留。

## 方法与结果

使用两个独立 Mihomo 进程，临时端口与数据目录，TUN 关闭；同一线路访问同一网址，正常／链式顺序交错。每个目标先预热一轮，再各测五次，共 160 个计入统计的请求。记录为新建 HTTP(S) 连接的 URL 检测耗时，包含连接与协议开销，不是 ICMP ping 或本机到节点的纯 RTT。未为了测试更改活动客户端、节点或系统代理。

链式路径没有显示整体且稳定的收益，按用户授权撤回；国内绕经 Jetson 的成本也不再保留。

## 回退复核

回退只撤销本次试验的代码与首跳服务，不恢复旧数据库。使用新鲜基线核对 21 份普通三格式订阅、身份与授权、源规则、签名密钥及截至回退前的原生流量前缀。旧的链式订阅查询参数回到稳定版的普通导出行为，后续刷新获得原版配置，不返回任何 Jetson 首跳。两端不再显示私有链式入口，首跳端口与计时任务停用，原有 Tailscale、VPS 核心、监测与计量保留。

客户端回退前已选中原版 Kenxu，保留这个选择；不批量修改本机其他订阅或现有节点选择。生产验证结果与逐次私有测量记录保存在受控工作目录。
