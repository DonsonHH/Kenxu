# 第一批交互反馈打磨

范围是原界面的复制订阅、登录／保存和顶部手动刷新。不是「轨道空间」整合，也不改导航、卡片布局、全局主题、字号体系、后端接口、订阅、节点或计量。之前的 `prototypes/round-one/` 保留，不参与正式构建或本次提交。

## 实现与动效 review

| Before | After | Why |
| --- | --- | --- |
| 复制成功同时改按钮并弹全局通知 | 原位「已复制」；保留不要转发的悬停／无障碍说明 | 减少重复提醒，操作结果仍可感知 |
| 表单统一「处理中…」 | 登录中／保存中／重置中／导入中，并设置 `aria-busy` | 让等待与当前动作对应，不制造百分比或人工等待 |
| 等待文案可能改变按钮占位 | 保留原宽度作为可收缩的最小值，恢复原 DOM 节点 | 不挤动相邻动作，也不因桌面宽度钉死手机布局 |
| 登录失败依赖全局提示 | 登录与改密在表单旁显示可访问错误；保留输入供重试 | 降低查找成本；配置源维护等重要错误仍走原提醒 |
| 手动刷新使用全局加载／成功通知 | 顶部按钮局部等待／成功反馈，失败保留错误提醒 | 等待时保留已有非零数据与图表，不整页闪动 |
| 复制的迟到结果可能落到已切换的格式 | 身份、交互批次、当前链接共同校验；会话／格式重置时清理 | 旧失败不能展开新格式链接，旧确认不能污染新会话 |
| 系统设置按钮只禁用、缺少提交入口守卫 | 原位保存反馈、重复提交守卫、身份与批次检查 | 与其他保存入口一致，不改变写请求内容 |

动效判定：仅为用户明确发起的等待提供状态指示。复用既有图标位置；纯文字保存按钮不另塞旋转图标。等待图标是 `transform` 的 800ms 线性循环，不是入场动画，只在指针发起且请求未结束时转动；键盘、减少动态效果时静止，页面隐藏时暂停。没有新增入场、抽屉、数字滚动、全屏背景或图表动画。原有色彩／按压过渡继续沿用项目 token。

动效 verdict：无需要保留的多余装饰，没有布局属性动画、`ease-in` 或 `scale(0)`；低动态与键盘反馈保留文字及状态，不依赖旋转传达结果。Approve。此结论只覆盖本批 diff，不是全站动效审计。

## 验证口径

- `node scripts/build.mjs`：重建现有前端产物，无新依赖。
- `node --run test`：现有核心接口、授权、安全、分流与计量回归。
- `$env:PLAYWRIGHT_CHANNEL='msedge'; node --run test:browser`：完整浏览器回归，新增 `test/browser-feedback.mjs`。
- 专项使用真实隔离应用、临时 SQLite、模拟剪贴板，以及在 HTTP 边界阻塞／失败的响应；不读真实浏览器资料，不访问真实节点。20 MB 非零用量来自临时计量账本，确保保留数据的断言不是空占位符。
- 专项检查：两端登录等待、防重复、真实登录拒绝、复制失败回退、切换格式后迟到失败、刷新失败不清数据、关闭重开的编辑不被旧保存清空、系统设置保存、规则冲突保留草稿。
- 浅深模式下分别检查 390、1440、2560、3840 CSS 像素的忙碌状态与按钮几何；键盘及减少动态效果时等待图标不旋转。截图仅包含虚构测试账号，见忽略目录 `test-output/feedback/`。

最终专项结果与生成时间见 `test-output/feedback/results.json`。全套回归以命令的成功退出为准，不用旧截图替代当前测试，也不把浏览器仿真称为实机触控验证。

最终结果：构建成功；79 项核心测试全部通过；14 个浏览器回归脚本串行运行并成功退出。专项的八种忙碌状态布局及失败／迟到响应检查通过，已人工查看登录错误、保存等待、复制等待和非零数据刷新截图。`git diff --check` 无空白错误。未发现需阻止本批本地提交的遗留问题。
