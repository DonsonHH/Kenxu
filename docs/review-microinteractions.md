## Before / After / Why

| Before | After | Why |
| --- | --- | --- |
| 图表范围与设备选择主要依赖点击 | 方向键、Home／End 和单一 Tab 停靠点；选中状态仍由原处理器维护 | 减少重复按 Tab，不改数据或导入逻辑 |
| 步骤按钮缺少组内键盘浏览 | 方向键只移动焦点，Enter 仍跳转并聚焦标题 | 不把阅读定位命令误作立即激活的页签 |
| 原生点击后若过早同步，Tab 停靠点可能落在旧选项 | 观察处理器已写入的 ARIA 状态，再同步停靠点 | 实际选中、显示与键盘状态一致 |
| 选中效果直接切换 | 图表／设备按钮的小底色、管理端页签下划线做 120ms opacity 过渡 | 不移动文本、尺寸或图表数据 |
| 直接滚动教程时步骤提示仍停在旧位置 | 文档可见时，观察当前设备的四个步骤，同步实际阅读位置 | 不抢焦点、不自动滚动、不勾选完成 |
| 「继续查看」命令也收到当前步骤标记 | aria-current 只用于步骤导航 | 避免对读屏用户重复声明当前位置 |
| 两端缺少一致的小范围悬停提示 | fine-pointer 下用 120ms 边框 opacity 提示可用动作 | 不抬升卡片，不改变原配色或大小，不提示禁用动作 |

## 实现与动效 review

- `public/choice-ui.js` 增强既有按钮，不生成新布局、不复制业务选择状态。图表范围、设备选择、步骤命令与原有 tablist 各保留原语义。管理端已有键盘／缓存处理器不被重复绑定；修饰键不被消费。
- 原生事件的 capture 回调里排 microtask 不保证晚于其他处理器，开发时已通过真实点击复现过旧停靠点。最终实现只观察各组选中属性，回调只改 tabindex；不靠延时猜测事件顺序。
- 视觉只插值伪元素 opacity，120ms，复用 `--ease-out`；保留原底色、选中阴影、边框占位、文字与尺寸。无 width／height 动画、弹跳、数字滚动或新动画依赖。
- 键盘／减少动态效果选择即时响应。程序更新和会话重置显式同步为无动效；业务轮询不新增选中切换。图表仍使用原来的 `animation:false`／`update('none')`，范围切换不重新读取统计。
- 阅读观察器仅在文档面板可见时工作，每次只观察当前设备的四个步骤。读取线复用现有 scroll-margin 与 padding；面板隐藏或重置时 disconnect 并取消待执行帧。没有 scroll 轮询或常驻 rAF 循环。不支持 IntersectionObserver 时保留手动导航。
- 阅读提示不是完成率，手动复选框保持独立。阅读滚动不做边框动画，原有手动步骤点击反馈保留。切换面板后根据实际可见位置恢复提示，不保留与画面不符的数字。
- hover 装饰仅存在于 `hover:hover / pointer:fine`，不接收事件。禁用动作不显示该提示；触摸不创建这一层。键盘仍用原 focus-visible，低动态保留即时状态。

Verdict：**Approve**，限于本批 diff 与已验证浏览器。无需要保留的多余动画或业务数据改动，不作整站 FPS、所有浏览器或实机触控认证。
