## Review：Before / After / Why

| Before | After | Why |
| --- | --- | --- |
| 手机导航只用 transform 移出屏幕，关闭后仍会收到 Shift+Tab 焦点 | 关闭态 `inert`、`aria-hidden` 与交互状态同步；桌面恢复普通导航 | 防止键盘走进屏幕外的导航 |
| 手机遮罩突然出现／消失，240ms 计时器清理动效类 | 侧栏与遮罩使用可反转的 CSS 过渡，无清理计时器 | 快速开关不会被旧计时器中断 |
| 打开菜单总聚焦第一个页面 | 聚焦当前页面，关菜单恢复触发按钮或选中页面标题 | 保持方向感和已有键盘约束 |
| 原生弹窗直接出现／消失 | 指针操作增加 200ms 淡入／.97 缩放及遮罩过渡 | 衔接空间变化，不改尺寸、内容布局或焦点容器 |
| 保存关闭后，列表重绘移除了原按钮，焦点可能丢失 | 渲染前记录语义入口，重绘后只修复失去的焦点 | 保存后继续停在对应账号，而非页面空处 |
| 旧保存重绘了列表，新草稿仍打开，随后关闭时原入口已断开 | 原生关闭后按稳定入口标记补回；只接管 body 或关闭弹窗内的无效焦点 | 不清空新草稿，也不抢走其他输入框的焦点 |
| 创建账号的入口在刷新期间被临时禁用 | 保存后的刷新保留语义返回点，等待原生关闭／刷新收尾 | 覆盖与编辑账号不同的焦点生命周期 |

## 实现边界

- `public/overlay-ui.js` 只包装现有 `showModal()`／`close()`，以 `dialog.open` 为真值。不修改原型，不延迟实际关闭，不用动画计时器清空表单，不克隆私有表单内容。
- MutationObserver 只观察四个既有弹窗的 `open` 属性，不扫描全页面。关闭后设置 inert，退出画面不能再次操作；原生焦点恢复优先，只有无效焦点才补回语义入口。
- 会话重置会立即清除返回点及 CSS 过渡；随后按原逻辑关闭和清空。真实 401 测试确认没有仍在绘制的退出弹窗或残留字段。
- 侧栏 220ms，沿用 `--ease-drawer`；遮罩沿用 `--ease-out`。弹窗沿用 `--ease-out`，缩放中心位于弹窗中心。键盘、Esc 和减少动态效果均即时响应；不新增背景、图表或计量数字动画。
- CSS 的 `display`／`overlay` 是原生可见性／顶层生命周期的**离散切换**，不是逐帧尺寸布局动画；视觉插值仅 opacity／transform。不支持相关特性的引擎保持原生即时弹窗。方法参考 [MDN 原生弹窗动画](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/dialog#animating_dialogs) 与 [starting-style](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@starting-style)。没有复制其 scale(0) 或长时长示例。
- 不新增依赖，不改 API、节点、授权、订阅、数据库结构或生产账号。`prototypes/round-one/` 保持原状且不参与本批构建／提交。

## 验证

新增 `test/browser-overlays.mjs` 并纳入完整浏览器回归，使用临时 SQLite、虚构账号及 loopback 应用。覆盖：

1. 隐藏侧栏的 Shift+Tab、打开后的当前页焦点、Tab 圈定、关闭恢复焦点。
2. 快速关闭／重开、点击导航项后语义立即关闭、遮罩最终消失、断点切换。
3. 四类原生弹窗的 modal 属性、原生焦点包含、关闭按钮、Esc、未提交密码清理。
4. 同一帧关闭／重开不丢新草稿；保存导致列表重绘后恢复对应入口；创建账号在刷新后恢复入口。
5. 原有生命周期测试增加断言：旧保存重绘列表后，新草稿关闭仍能返回其替换后的按钮。
6. 指针／键盘／减少动态效果，浅深模式下 390、1440、3840 CSS 像素的布局。
7. 在真实 CSS 过渡 70ms 处暂停并截图，另查看手机弹窗和导航截图；无图像后处理。机器结果见忽略目录 `test-output/overlays/results.json`。这不是实机触控或 Safari／Firefox 认证。

`test/xboard-ui.mjs` 原有“点击导航后遮罩立即 isVisible=false”改为立即检查 hidden、aria-expanded、main.inert，再等待视觉淡出。没有放宽会话过期必须立即清理私有界面的断言。

复现的焦点根因：原触发按钮可能被列表重绘移除，浏览器仍把焦点留在已关闭但退出过渡中的输入框；仅检查 activeElement===body 不足。修复后这一真实迟到响应路径通过，而非把测试改成忽略焦点。创建操作另等待原生关闭与刷新后的可观察返回焦点，不依赖单帧断言。

最终结果：构建成功，79 项核心测试全部通过，15 个浏览器回归脚本完整串行运行并成功退出；第一批反馈测试继续通过。专项连续复跑三次通过；随后只去掉了未使用的入口 DOM 引用，并重新执行完整回归。`git diff --check` 无空白错误，调试日志已移除。
