    4 步入门

    电脑 · Clash Verge

    Windows、macOS 和 Linux，从安装到连接

    当前查看 · 第 1 步 安装客户端

    1

    安装客户端

    选择官方稳定版，按电脑的系统与处理器架构下载安装。

    下载 Clash Verge官方 Releases · 稳定版安装包
    多数 Windows 电脑用 x64；Apple Silicon Mac 用 ARM64，Intel Mac 用 x64。Linux 按发行版选择，具体文件名以官方说明为准。
    2

    导入并选中订阅

    打开本站「我的订阅」，确认客户端为 Clash Verge，再点击导入。在应用中确认，并选中 Kenxu 配置。

    没有自动打开？手动添加

    复制订阅链接，到 Clash Verge 左侧「订阅」粘贴并导入，然后选中这份配置。链接只交给自己的客户端。

    3

    保持规则模式，选择线路

    打开客户端左侧「代理」，右上角保持「规则」。在 Donson - Proxy 先试 SG Load Balance，蓝色卡片表示当前选择。

    普通访问由 Donson - Proxy 决定

    AI 网站单独检查 AI Policy

    Microsoft单独检查 Microsoft Policy

    切换主代理组不会改变专用组。Load Balance 是一组节点，不是一台服务器；延迟数字也不是下载速度。

    查看截图与策略组说明

    下面是电脑端真实界面示例，可点击图片放大；可选项以你的授权为准。

    4

    开启系统代理，验证访问

    在客户端「首页」或「设置」开启系统代理，再用浏览器访问目标网站。应用不使用系统代理时，按客户端说明配置 TUN。

    勾选你已确认的项目

    这些是需要你确认的操作，不会由网站自动判定。仍打不开时先测节点、更新订阅，再查看下方常见问题。

    打开应用连接开关，按系统提示允许添加 VPN 配置，并由你确认设备密码或生物识别。连接后实际打开目标网站。

    常见问题

    订阅校验提示 unsupported rule type

    提示 PROCESS-PATH-WILDCARD 或 PROCESS-NAME-WILDCARD 不受支持，说明内核不认识该类型。本站已改为兼容的正则导出：在 Clash Verge 的「订阅」卡片右侧点击刷新，更新 Kenxu 订阅后重新选中。下载的本地 YAML 需要重新下载。

    仍出现同类通配符时，检查全局覆写、扩展脚本或合并配置是否加入旧规则，或从官方渠道更新 Clash Verge Rev 及其配套内核。反馈时提供错误最后一行和版本，不要发送订阅链接、密码或完整配置。

    已经导入，但网站打不开

    先确认这份订阅已选中、客户端正在运行；电脑开启系统代理，手机允许并启动 VPN。Clash／Stash 保持规则模式并测试连接，AI 或 Microsoft 网站单独失败时检查对应组；Shadowrocket 检查所选节点和应用自己的路由设置。切换后重新打开页面，仍沿用旧连接时可在客户端「连接」中关闭那条连接后重试。

    仍失败时更新订阅再试。联系 Donson 时说明客户端版本、所选组和节点、出错时间或提示；截图时遮住订阅链接和密码。

    为什么主代理组换了，AI 或 Microsoft 仍走原来的节点？

    「规则」模式按请求匹配分流。命中 AI Policy 或 Microsoft Policy 的请求由各自的选择决定，需要进入对应组调整。

    网页显示「正常」，客户端却超时

    「正常」表示 Jetson 最近通过该源节点成功访问了检测网站，默认每 15 分钟检测一次。你的网络、客户端到公开中转入口的连接可能不同；请结合客户端测试和实际访问判断。网页刷新不会反复触发节点检测。

    订阅多久更新一次？

    本站默认建议每 720 分钟，也就是 12 小时更新。管理员调整线路后可以手动更新。已有订阅若保存了其他间隔，在客户端「订阅」卡片的「编辑信息」中修改，界面名称可能随版本不同。

    下载 YAML 和导入订阅有什么区别？

    远程订阅可以更新线路，并读取本站返回的本月用量信息。下载的 YAML 是当时的配置副本，作为本地文件导入后不会自动获得新的线路或订阅用量；平时优先使用自己的订阅链接。

    超过 100 GB 会被停用吗？

    不会。100 GB 是默认的月用量展示参考，实际数值以你的账户卡片为准，不限制流量。每月 1 日按北京时间重算本月用量，累计记录保留。

    网页和 Clash Verge 卡片的用量为什么不同？

    网页默认每分钟更新；Clash Verge 的订阅卡片通常在更新订阅时才读取最新本月用量。客户端左下角的实时速率和本机累计数字也不是这个账号的本月统计。本站只记录经分配入口的上传与下载，不包含直连流量。

    本站记录哪些使用信息？

    受管线路记录账号用量、连接来源 IP、目标域名或 IP 和连接字节，供管理员排查异常用量；使用明细保留 30 天。不记录网页路径、请求正文，也不解密 HTTPS。个人中心仅在最近使用 IP 后显示国家、省市归属，不展示来源历史或访问目标。进入个人中心时，若缓存缺失，仅将这一条已观察的公网 IP 发给 IPinfo Legacy Free 补查，成功缓存 7 天，失败退避 5 分钟；不发送账号或访问目标。归属为估算，不是具体住址。直连和不计量备用线路不在记录范围内。

    登录提示尝试过多，或者忘了密码

    按页面倒计时等待后再试，确认账号和密码输入正确。忘记密码请联系 Donson 重置；不要连续猜测密码。新初始密码仍需在首次登录时修改。

    订阅链接泄露了怎么办？

    在「我的订阅」重置链接，再把新链接导入客户端。重置会让旧订阅链接失效，但已下载的节点凭据不会自动更换；若别人已经拿到配置，请同时联系管理员处理。
