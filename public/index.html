    4 步入门

    邀请制共享，请勿转发账号或订阅。服务不保证持续可用；遇到问题可先按下方步骤排查，再联系 Donson。

    电脑 · Clash Verge Rev

    Windows / macOS / Linux

    步骤导航 · 1 / 4 安装客户端

    1

    安装客户端

    打开官方发布页，在最新稳定版的 Assets 中选择安装包。不要下载 Source code，也不必选择 Pre-release 测试版。

    下载 Clash Verge Rev官方最新稳定版 · 选择适合电脑的安装包

    Windows多数电脑选 x64-setup.exe；ARM 电脑选 arm64-setup.exe。

    macOSApple Silicon（M 系列）选 aarch64.dmg；Intel Mac 选 x64.dmg。

    Linux按发行版选择 .deb 或 .rpm，架构与设备保持一致。安装要求以官方说明为准。

    GitHub 暂时打不开时，稍后重试或联系 Donson 获取安装帮助，不要随意安装来源不明的客户端。

    2

    导入并选中个人订阅

    前往「我的订阅」，确认客户端为 Clash Verge，再点击「一键导入」。允许浏览器打开应用，在客户端确认导入，并选中 Kenxu 配置。

    没有自动打开？手动添加
    1. 在本站「我的订阅」复制当前个人链接。
    2. 打开 Clash Verge 左侧「订阅」，把完整链接粘贴到订阅链接框并导入。
    3. 点击新出现的 Kenxu 配置卡片，确认它处于选中状态。

    优先导入远程订阅，而不是下载一份不会自动更新的本地 YAML。链接相当于领取配置的凭证，请勿转发或贴入公开截图。

    3

    保持规则模式，选好两个组

    进入左侧「代理」，右上角保持「规则」。日常只需要关注下面两个选择组，其他辅助分流由配置处理。

    普通访问 · Donson - Proxy可先选 SG Load Balance

    AI 网站 · AI Policy可先选 US Load Balance

    主代理组切换不会覆盖 AI 组的选择。Load Balance 是节点组，不是一台服务器，也不意味着带宽相加。

    查看截图与策略组说明

    这是当前电脑界面的示例；实际可选线路以你的授权为准。点击图片可放大。

    4

    开启系统代理，实际访问验证

    在客户端「首页」或「设置」开启系统代理，再用浏览器打开你需要的网站。连接测试出现数字只能辅助排查，实际能打开目标网站才是本次验证结果。

    哪些情况需要 TUN？

    部分应用不使用系统代理，才需要按客户端说明配置 TUN。不要为了排查网页而反复同时修改多个开关；先用浏览器完成基础连接验证。

    阅读 Clash Verge Rev 官方快速入门

    勾选你已确认的项目

    这些检查项由你自行确认，网站不会自动检测你电脑的连接。

    Android · Clash Meta for Android

    安装 APK，导入配置，允许 VPN 连接

    步骤导航 · 1 / 4 安装 Android 客户端

    1

    安装 Android 客户端

    从官方最新稳定版的 Assets 下载 APK，避开 Pre-release / alpha。多数现代手机适用 arm64-v8a-release.apk；架构不确定时先查看设备信息。

    下载 Clash Meta for Android官方最新稳定版 · Android APK

    按系统提示允许此次 APK 安装，完成后可关闭浏览器的安装授权。无法下载或安装时，联系 Donson，不必从不明镜像反复尝试。

    2

    导入并保存 Kenxu 配置

    下面的入口会在订阅页选好 Android 客户端。点击「一键导入」，在应用中确认并保存；链接使用你自己账号的授权配置。

    从 URL 手动导入
    1. 复制订阅页当前链接，打开应用「配置」→「＋」→「从 URL 导入」。
    2. 名称填 Kenxu，URL 粘贴完整个人链接。
    3. 自动更新间隔可设为默认建议的 720 分钟（12 小时），然后保存；若站点设置已调整，以新建议为准。
    3

    选中配置，保持规则分流

    在「配置」选中 Kenxu。回到首页启动连接后，进入「代理」页面，保持规则模式，再确认这两个组的选择。

    普通访问 · Donson - Proxy可先选 SG Load Balance

    AI 网站 · AI Policy可先选 US Load Balance

    不熟悉策略组？展开对照说明

    下图是电脑界面，只用来对照相同组名，不是 Android 操作截图。Android 按客户端实际入口操作。

    4

    允许 VPN，测试目标网站

    首次启动时允许 Android 的 VPN 连接请求，确认应用显示正在运行，再实际打开目标网站。VPN 标识和延迟数字都不能代替实际访问。

    勾选你已确认的项目

    避免另一款 VPN 同时接管网络。若锁屏后频繁断开，再按需允许客户端后台运行或调整系统省电设置；不使用时可主动停止。

    iPhone / iPad

    选好应用，用 Safari 导入个人订阅

    步骤导航 · 1 / 4 获取客户端

    1

    用自己的 Apple 账号获取客户端

    选择已购买或适合自己的应用。可用地区、价格和系统要求以 App Store 为准；无法获取时联系 Donson，不要借用陌生人的 Apple 账号。

    获取 ShadowrocketApp Store · 节点订阅获取 StashApp Store · 策略组与规则

    Shadowrocket选择具体节点，使用应用自己的路由设置。

    Stash使用适配后的 iOS YAML，保留本站策略组和域名规则。

    2

    按应用导入对应的个人订阅

    在 Safari 打开本站，选择下面的入口。订阅页会切换到对应格式，再点击「一键导入」并允许打开应用；不要把 Clash YAML 链接直接当作 Shadowrocket 节点订阅。

    没有跳转到应用？手动添加
    1. 先在本站「我的订阅」选对客户端，再复制当前个人链接。
    2. Shadowrocket：首页「＋」→ 类型选 Subscribe（订阅）→ URL 粘贴链接 → 保存并更新。
    3. Stash：在配置管理中从 URL 下载，粘贴为 Stash 提供的 iOS YAML 链接，然后选中这份配置。

    微信等内置浏览器可能拦截应用唤起，可改用 Safari。不要扫描其他人的共享订阅二维码。

    3

    按应用选择线路与分流

    Shadowrocket：选择节点

    更新订阅后，从节点列表选择一条可用线路。它使用应用自己的全局路由设置，不包含 Clash 的两个选择组；不要照搬电脑的组选择步骤。AI 网站不可用时，可测试并切换已授权的美国或英国线路，再实际访问验证。

    Stash：选择策略组

    选中 Kenxu 配置，保持规则分流：普通访问可先用 Donson - Proxy → SG Load Balance，AI 网站可先用 AI Policy → US Load Balance。后台辅助组无需手动展开。iOS 配置省略电脑进程规则，DNS 使用 Stash 设置。

    查看组名与分流说明

    这是电脑端参考图，仅对照组名和用途，不是 Stash 的操作截图。

    4

    允许 VPN 配置，验证连接

    打开应用连接开关，按 iOS 提示允许添加 VPN 配置；设备密码或生物识别只在系统提示中由你确认，不要提交给网站。连接后实际打开目标网站。

    勾选你已确认的项目

    可按需在客户端开启订阅自动更新，但 iOS 后台更新并非总能及时执行。线路调整后，手动更新订阅更直接。

    遇到问题，按顺序排查

    已经导入，但网站打不开
    1. 确认导入的是自己的最新订阅，并已在客户端选中。
    2. 电脑开启系统代理；手机允许 VPN 并确认正在连接。
    3. Clash / Stash 保持规则模式，检查普通访问和 AI 两个组；Shadowrocket 检查所选节点与自身路由设置。
    4. 先更新订阅并测试线路，再实际访问目标网站。切换后若仍沿用旧连接，可关闭客户端中对应的连接再重试。

    延迟数字、VPN 标识和网页显示「正常」，都不能替代本机的实际访问验证。

    只有 AI 网站有问题，或切换主组后没有变化

    Clash / Stash 的 AI 请求由 AI Policy 独立选择，切换 Donson - Proxy 不会覆盖它。先查看本站「AI 状态」是否有对应官方故障，再测试和切换 AI 组的可用线路。Shadowrocket 使用自己的节点选择与路由设置。

    节点正常不保证所有地区、账号或模型可用。不要提供 AI 账号、密码或 API 密钥来排查。

    一键导入没有打开客户端

    先安装对应应用，再从系统浏览器打开本站。微信等内置浏览器中可切换到 Edge / Chrome / Safari。仍无法唤起时，在「我的订阅」选好客户端，复制当前链接，按对应设备第 2 步手动导入。

    订阅校验提示 unsupported rule type

    提示 PROCESS-PATH-WILDCARD 或 PROCESS-NAME-WILDCARD 不受支持时，先在订阅卡片中刷新 Kenxu，再重新选中配置；本地 YAML 则需重新下载。本站导出已做兼容处理。

    仍出现旧通配符时，检查全局覆写、扩展脚本或合并配置，也可更新官方客户端及其配套内核。联系 Donson 时提供错误最后一行、客户端和内核版本，不要发送完整配置或订阅链接。

    网页显示正常，客户端却超时

    网页展示 Jetson 最近对源节点的定时检测，默认每 15 分钟一次，不代表你本机到入口的网络。请结合客户端测试和实际访问判断；刷新网页不会立即重新检测节点。

    订阅多久更新？下载 YAML 有什么不同？

    默认建议每 720 分钟（12 小时）更新，以站点最新设置为准。已有客户端可能保留自己的间隔；线路调整后可以手动刷新。远程订阅可获取新线路，并由兼容客户端读取本月用量信息。

    下载的 YAML 只是当时的配置副本，作为本地文件导入后不会自动收到后续修改或订阅用量。因此日常优先使用个人远程订阅。

    为什么网页与 Clash Verge 的用量不一样？超过 100 GB 会停用吗？

    网页默认每分钟读取统计；订阅卡片通常在更新订阅时才读取本月用量。客户端左下角的实时速率、本机累计和本站账号的本月总量不是同一个口径。本站记录受管入口的上传与下载，不包含直连。

    100 GB 是默认月展示参考，不限流、不停用，具体展示额度以账户卡片为准。每月 1 日按北京时间重算月视图，累计记录保留。

    账号、订阅链接和使用信息如何保护？

    不要共享账号或链接。登录提示尝试过多时按倒计时等待，忘记密码请联系 Donson 重置，不要反复猜测。新初始密码仍需首次登录修改。

    链接泄露时，在「我的订阅」重置后重新导入。旧链接会失效，但已下载的节点凭据不会自动更换，必要时同时联系管理员处理。

    受管线路记录账号用量、连接来源 IP、目标域名或 IP 和连接字节，使用明细保留 30 天；不记录网页路径、正文，不解密 HTTPS。个人中心只展示最近使用 IP 及归属估算；直连和不计量备用线路不在记录范围内。

    若最近 IP 的归属缓存缺失，仅将这一条公网 IP 发给 IPinfo Legacy Free 补查，不发送账号或访问目标。成功缓存 7 天，失败退避 5 分钟；归属是估算，不是具体住址。
